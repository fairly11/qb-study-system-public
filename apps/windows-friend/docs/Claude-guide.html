QB STUDY FRIEND · CLAUDE DESKTOP

Claudeに導入と復習セット作成を任せる

1.1.0-preview

復習候補はQB Study Friendが計算し、Claudeはアプリの操作、QBへの問題追加、保存結果の確認を担当します。自分で操作する場合は、通常の導入手順を使ってください。

  • 接続を準備する
  • 導入を依頼する
  • 毎日の復習を依頼する
  • コマンドから操作する
  • 定期実行を設定する
  • Claudeへ渡すもの
  • 完了時に確認すること

接続を準備する

Claudeから、このWindowsのファイルとChromeを操作できる接続が必要です。利用できるプランと設定方法は、CoworkとClaude in Chromeの公式案内を確認してください。

  1. WindowsでClaudeデスクトップを開き、自分のアカウントへログインします。
  2. Chromeに公式のClaude in Chromeを導入し、Claudeデスクトップから利用できるよう接続します。QB記録用の拡張とは別の拡張です。
  3. ChromeでQBへログインします。パスワード入力や追加認証は自分で行ってください。
  4. 配布ZIPを展開し、docs の手順をClaudeへ渡します。設定後の data フォルダーは渡さないでください。
  5. Claudeが対象のフォルダーとChromeを操作できることを確認します。ファイル操作が使えない場合は、install.cmd と start.cmd を自分でダブルクリックして起動できます。

作業中はPC、Claudeデスクトップ、Chrome、記録サービスを起動しておきます。クラウド側で会話が動いていても、スリープ中のPCの画面やファイルは操作できません。

導入を依頼する

  1. 導入の依頼文を読み、内容を確認してClaudeへ貼り付けます。通常の導入手順も渡してください。
  2. Claudeの案内に沿ってWindowsへ導入し、自分のNotionに専用ページと内部接続を作ります。
  3. 接続キーを入力する段階ではClaudeの操作を止め、自分で操作画面の秘密入力欄へ貼り付けます。
  4. Notionに保存先が作成されたら、普段の学習で1〜2問解答します。
  5. Claudeに問題番号、選択記号、正誤、日時、件数を照合させ、PCとNotionに同じ記録があることを確認します。

毎日の復習を依頼する

  1. start.cmd でQB Study Friendを起動します。
  2. 日常運用の依頼文をClaudeへ送ります。初回はこの手順も渡してください。
  3. Claudeが候補を計算し、QBに計画どおりのセットを作成します。中断した場合は、保存済みの計画と同じセットから再開します。
  4. QBセットの全件照合とNotionへのリンク保存が終わったら、報告されたリンクから復習を始めます。

候補は最大100問です。問題数に応じてブラウザ操作の時間とClaudeの利用枠を使います。利用制限に達した場合も、途中のセットを消さずに再開してください。

iPhone / iPadを併用する場合は、計算前に送信待ちがNotionへ届いていることを確認します。Windows画面の「PCに保存」の件数には、他の端末の解答は含まれません。

コマンドから操作する

ClaudeがこのWindows上でコマンドを実行できる場合は、操作画面の代わりに review.cmd を使えます。先に start.cmd で記録サービスを起動してください。

状態を確認するコマンドです。実行するフォルダーは任意です。

Windows PowerShell：

& "$env:LOCALAPPDATA\QBStudyFriend\review.cmd" status

コマンドプロンプト：

"%LOCALAPPDATA%\QBStudyFriend\review.cmd" status

記録件数、review.day（復習対象日）、準備済みなら review.manifest（セット名と問題番号）をJSON形式で返します。このコマンドは状態を読むだけで、QBやNotionには書き込みません。

続く操作では、YYYY-MM-DD を status の review.day に置き換えます。

引数処理
prepare YYYY-MM-DD候補を計算し、PCに計画、Notionに候補ページを保存します。同日計画があれば再利用します。
begin YYYY-MM-DDセット作成の開始をPCへ記録します。QBセット自体は作りません。返された may_create と既存セット情報を確認して、新規作成か再開かを判断します。
remaining "C:\絶対パス\observed.json"QBから読み取った途中の番号列が計画の先頭と一致するかを確認し、残りを返します。外部への書き込みはありません。
register "C:\絶対パス\verified.json"QBのURLと確認済み番号を照合し、PCに照合結果、Notionにセットリンクを保存します。QBへの問題追加は別途行います。

入力JSONはWindowsの一時作業フォルダーへ作成します。次の説明部分を実際に確認した日付・番号・URLへ置き換えてください。

remaining 用：

{"day":"対象日","ids":["QB上で確認した番号","次の番号"]}

register 用：

{"day":"対象日","url":"同じQBセットの検索画面URL","ids":"番号を改行で区切った文字列","confirmed":true}

confirmed は、QB上の全件を確認したときだけ true にします。保存済み計画の転記では、QBへの登録は確認できません。登録後はNotionを開き直し、同じリンクが保存されていることを確認してください。

接続キーはプログラムが内部で扱います。Claudeへ session.json やキーを渡す必要はありません。data や設定ファイルを直接書き換えず、このコマンドか操作画面を使ってください。

定期実行を設定する

まず、候補計算からQBセット作成、Notionのリンク確認までを手動で一度実行します。その後、利用中のClaudeに定期実行機能があれば設定できます。

  1. 日常運用の依頼文を使い、実行する時刻とタイムゾーンを指定します。日本時間の午前4時より前は、前日分の復習として扱われます。
  2. 保存された時刻、タイムゾーン、指示内容を管理画面で確認します。
  3. 実行時刻にPC、Claudeデスクトップ、Chrome、記録サービスを利用できる状態にします。
  4. 初回の予約実行後、QBセットとNotionのリンクを確認します。未完了なら、その日の保存済み計画から再開します。

同日の確認を再実行するときも、同じ計画と同じセットを使います。autostart-on.cmd は記録サービスの起動設定であり、Claudeの定期実行とは別です。

渡すもの渡さないもの
導入手順、復習候補の問題番号、セット名、件数、URL、確認用コードNotion接続キー、パスワード、Cookie、セッションファイル、設定後の data フォルダー

操作結果が不明な場合は、保存先を開き直して確認してから続けます。OSやClaudeが操作を拒否した場合は、その操作と理由を確認してください。

完了時に確認すること

  1. 復習対象日と計画の問題番号が確定している。
  2. QBセットの全ページを再読み込みし、番号、件数、順序、重複、欠落が計画と一致している。
  3. Notionの候補ページに同じQBセットのリンクが保存されている。

候補0問の場合は、Notionの「候補なし」のページを確認します。途中で停止した場合は、保存済みセットのURLと再開位置を報告させてください。
