QB STUDY FRIEND · WINDOWS 11

導入と毎日の使い方

1.1.0-preview

WindowsでQBの解答を記録し、Notionに集めた履歴から毎日の復習候補を選ぶアプリです。QBのセット作成は手動で行うか、Claudeに依頼できます。

Windows実機での動作は未検証です。導入後は普段の学習で1〜2問解き、PCとNotionの記録が一致することを確認してください。確認項目は検証の範囲を参照してください。

用意するもの

  • Windows 11のPC、Google Chrome、QBのアカウント。
  • 内部接続を作成できる、自分のNotionワークスペース。
  • インターネット接続。導入時にNode.jsの実行環境を公式サイトから取得します。

Claudeは任意です。利用する場合は、WindowsのファイルとChromeを操作できる環境をClaude用の手順に沿って準備してください。

WindowsのSモードや組織の管理設定で実行できない場合は、保護機能を無効にせず、表示されたエラーを管理者へ確認してください。

1. Windowsへ導入する

  1. ZIPを右クリックし、「すべて展開」を選びます。ZIPを開いただけの画面からは実行しないでください。
  2. 展開したフォルダーの install.cmd を通常ユーザーとしてダブルクリックします。「管理者として実行」は使いません。
  3. Installed: と設置先が表示されるまで待ちます。設置先は %LOCALAPPDATA%\QBStudyFriend です。既存のフォルダーがある場合は停止するため、履歴を消して再インストールしないでください。
  4. start.cmd をダブルクリックします。Chromeに操作画面が開き、「記録サービス：起動中」と表示されることを確認します。記録サービスのウィンドウは開いたままにします。
  5. Chromeで chrome://extensions を開き、「デベロッパーモード」を有効にします。「パッケージ化されていない拡張機能を読み込む」から %LOCALAPPDATA%\QBStudyFriend\browser-extension を選びます。

ChromeにはZIPの展開先ではなく、上記の設置先を登録します。登録後にこのフォルダーを移動すると、拡張が読み込めなくなります。

操作画面は start.cmd から開いてください。起動直後のURLには操作用の秘密情報が含まれるため、他人へ送らないでください。

学習データは設置先の data に保存します。Notion接続とWindowsログイン時の自動起動は、以下の手順で設定します。

2. Notionへ接続する

解答を始める前に設定してください。設定前にPCへ保存した記録は、後から自動ではNotionへ転送されません。

内部接続は、プログラムに指定したNotionページの読み書きを許可する設定です。接続キーはパスワードと同様に扱い、操作画面の秘密入力欄へ入力してください。

  1. Notionに新しい空のページを作ります。名前は「QB学習」などで構いません。
  2. Notion公式の内部接続の案内に沿って、そのページがあるワークスペースに内部接続を作ります。
  3. 接続にコンテンツの読み取り、挿入、更新を許可し、手順1のページとその子ページへのアクセスを設定します。
  4. 操作画面の「空の専用ページのURL」へページURLを入れ、秘密入力欄へ接続キーを貼り付けます。
  5. 「Notionの保存先を作る」を1回押して待ちます。
  6. 接続済みになったらNotionの専用ページを開き直し、「QB問題マスター」と「QB解答ログ」があることを確認します。初回は空の表で正常です。

途中で失敗した場合は、専用ページに作成済みの表があるか確認してください。新しい接続や表を繰り返し作らず、困ったときの手順で再開します。

3. 最初の記録を確認する

  1. ChromeでQBを新しいタブに開き、ログインします。
  2. 普段の学習で1〜2問解答します。
  3. 操作画面の「記録を更新」を押し、問題番号、選択記号、正誤、解答日時を確認します。「同期待ち」がある間はNotionへの送信が終わっていません。
  4. 各記録の「保存済み・開く」からNotionを開き、同じ記録が1件ずつあることを確認します。

「PCに保存」の件数は、このPCで取得した解答だけを数えます。iPhone / iPadの記録も同じNotionへ届いていれば、次の復習計算の対象になります。

毎日の学習と復習

学習する

start.cmd で記録サービスを起動し、ChromeでQBを使います。問題画面では自動で記録が始まります。学習後はNotionへの同期状況を確認してください。送信待ちを残して終了した場合は、次回起動時に再試行します。

復習候補を作る

「今日の復習候補を作る」を押すと、Notionに届いた解答履歴から最大100問を選びます。対象は第116回〜第120回の国試問題です。同じ優先分類の候補では、第120回の忘却リスクを1.25倍にして比較します。

日本時間の午前4時を1日の境界とし、その対象日の翌朝4時より前に復習期限を迎える問題を候補に含めます。保存済みの同日計画は固定され、その後の学習で自動的に入れ替わりません。候補が少ない場合は100問まで補充せず、0問ならQBセットを作りません。

通常学習、復習、未分類の正誤は、いずれも復習時期の計算に使います。正誤が未判定の記録は履歴に残し、記憶状態の更新には使いません。

QBに同じセットを作る

手動で行う場合は次の手順です。Claudeに任せる場合は、Claude用の手順と日常運用の依頼文を使います。

  1. QBの問題セット一覧が開けることを確認してから、操作画面の「QBセットの登録を始める」を押します。
  2. 表示されたセット名と完全に一致するセットをQBで探します。既存のセットがあれば再開し、新規作成が許可されている初回だけ、その名前で1つ作ります。
  3. 候補の順に1問ずつ追加し、QBの保存を確定します。「追加日時の古い順」に並べ、最初の5問で番号と順序を確認します。
  4. 全件追加後、QBのセットを再読み込みします。全ページの問題番号、件数、順序、重複、欠落を確認してください。連問が余分に入っていないかも確認します。
  5. QBで確認した番号を「QB上で確認した全問題番号」へ入力し、同じセットの検索画面URLを入れます。候補一覧の転記だけでは、QBへの保存は確認できません。
  6. 確認欄をチェックし、「内容を照合して復習セットを登録」を押します。完了後、Notionの候補ページを開き直し、同じQBセットへのリンクを確認します。

復習時は、登録済みセットのリンクから演習を開始します。通常検索や問題への直接移動では原則「通常学習」となり、セットの実施数には含まれません。現在の演習は拡張から「通常学習」「復習課題」を手動選択できます。セット照合に失敗した場合は「判定未確認」と表示します。

iPhone / iPadと併用する

iPhone / iPadにはSafari拡張を別途導入します。端末の「QB記録」に、Windowsと同じ解答ログ・問題マスター・復習計画の親ページのIDと接続キーを設定してください。3つのIDはWindowsの操作画面で確認できます。

Safariでは解答後に同期を試みますが、アプリを閉じた後の処理はOSによって止まることがあります。復習候補を作る前に、端末の送信待ちがNotionへ届いていることを確認してください。

停止・自動起動・更新

操作手順
記録サービスを停止するstop.cmd を実行します。記録サービスのウィンドウが閉じ、操作画面が停止または未接続になったことを確認します。
ログイン時の自動起動を有効にするautostart-on.cmd でYESを入力します。復習セット作成の予約は別途設定します。
自動起動を解除するautostart-off.cmd を実行します。起動中の記録サービスは、別に stop.cmd で停止します。
更新するインストーラーは既存フォルダーを上書きしません。設置フォルダーと data を保持したまま、使用する版の更新手順を確認してください。

設定後の設置フォルダーと data には、接続キーと学習履歴が含まれます。他人へ渡すときは元の配布ZIPを使ってください。

困ったとき

状態確認すること
操作画面が開かない・未接続start.cmd から開き直します。すでに起動中の記録サービスがないかも確認してください。
Notionの初期設定に失敗接続先の専用ページへのアクセス権を確認します。作成結果が不明な場合はページを開き直し、表を重複して作らないようにします。
PCには保存されたが同期待ちネット接続と記録サービスを確認し、しばらく待って「記録を更新」を押します。送信待ちや履歴ファイルは削除しないでください。
復習候補が0問初日や復習期限前なら、候補がない場合があります。同期前の記録が残っていないかも確認してください。
セット作成の途中で停止保存済みの計画と同じURLのセットから再開します。保存結果が不明なときは、再読み込みで確認してから追加を続けます。
番号や順序の不一致、同名セットの重複追加を止め、計画と保存済みセットの相違を確認します。既存問題の削除や別セットの作成で解消しようとしないでください。

問い合わせには、実行した操作、画面の確認用コード、対象日、件数を記載してください。接続キー、設定ファイル全文、起動用URL、QBの問題文や解説は送らないでください。
