QB STUDY FRIEND · WINDOWS 11

導入と毎日の使い方

1.1.0-preview ／ 2026年10月29日

Windowsで解答を記録し、自分のNotionに保存して、日々の復習候補を作ります。Claudeにセット作成を任せる場合は、Claude用の導入・運用手順を続けてお読みください。

Windows実機での動作確認は未実施です。この配布版は、開発環境での検査と実機での検査を分けて扱う試用版です。導入後は、普段の学習で1〜2問を解き、PCとNotionの記録が一致することを確認してください。詳しい検証範囲は配布物の検証記録を参照してください。

用意するもの

  • Windows 11のPCとGoogle Chrome。Windowsの通常の利用者として作業します。
  • 本人が利用できるQBのアカウントと、本人のNotionワークスペース。
  • インターネット接続。導入時にプログラムの実行に必要なNode.jsを公式サイトから取得します。
  • Claudeに操作を任せる場合は、有料版ClaudeとWindowsのClaudeデスクトップアプリ。本人が操作する場合、Claudeは不要です。

このZIPに、iPhoneアプリ、QBの問題本文、解説、画像、他人の学習履歴や接続キーは含みません。iPhoneアプリは別の配布経路で導入します。

WindowsのSモードや組織の制限で実行できない場合は、保護機能を無効にせず、表示されたエラーを確認してください。

1．Windowsへ導入する

  1. 受け取ったZIPを右クリックし、「すべて展開」します。ZIPを開いただけの画面からは実行しません。
  2. 展開したフォルダーの install.cmd をダブルクリックします。「管理者として実行」は使いません。
  3. 導入先は %LOCALAPPDATA%\QBStudyFriend です。実行環境のダウンロードと検査後、Installed: と設置先が表示されれば導入処理は完了です。既に同じフォルダーがある場合は上書きせず停止します。既存フォルダーを削除してやり直さないでください。
  4. start.cmd をダブルクリックします。Chromeに操作画面が開き、「記録サービス：起動中」と表示されることを確認します。記録用の黒いウィンドウは開いたままにします。
  5. Chromeで chrome://extensions を開き、右上の「デベロッパー モード」をオンにします。「パッケージ化されていない拡張機能を読み込む」を押し、%LOCALAPPDATA%\QBStudyFriend\browser-extension を選びます。フォルダー選択画面のアドレス欄にこの場所を入力できます。
  6. QB記録用の拡張が有効になっていることを確認します。展開したZIP内ではなく、上記の設置先を読み込みます。読み込み後にこのフォルダーを移動しないでください。

操作画面は start.cmd から開いてください。起動直後のURLには接続確認用の情報が含まれ、画面の読み込み後に取り除かれます。起動直後のURLや秘密の接続情報をチャットへ貼ったり、他人へ送ったりしないでください。

導入で変わるもの：本人専用フォルダーにプログラムと実行環境を設置します。学習データはその中の data に保存されます。初回導入だけではNotionへ接続せず、Windowsログイン時の自動起動や毎朝の復習予約も登録しません。

2．自分のNotionへ接続する

先にこの設定を済ませてから解答してください。設定前にPCへ保存された記録は、後から自動でNotionへ転送されません。

内部接続：このプログラムが、指定したNotionページを読み書きするための接続設定です。接続キーはパスワードと同様に扱い、Claudeや配布者へ送らず、本人が操作画面の秘密入力欄へ貼り付けます。

  1. 自分のNotionに新しい空のページを作ります。名前は「QB学習」などで構いません。既存の学習ページや他の人から共有されたページは選びません。
  2. Notion公式の内部接続の案内からDeveloper portalを開き、Internal connections で新しい接続を作成します。接続名は「QB Study Friend」などとし、先ほどのページがある自分のワークスペースを選びます。ワークスペースのオーナー権限が必要です。
  3. 接続の機能はコンテンツの読み取り、挿入、更新を有効にします。ユーザー情報の読み取りはこの用途では不要です。
  4. Content access の Edit access で、手順1の専用ページだけを接続に共有します。Notionのページ右上「…」から「Connections／接続」→「接続を追加」で同じ接続を選ぶ方法もあります。子ページへのアクセスも引き継がれます。
  5. 接続の Configuration にある秘密の接続キーを本人がコピーします。キーをチャット、メモ、スクリーンショットに残す必要はありません。
  6. QB Study Friendの「空の専用ページのURL」に手順1のページURLを入れ、接続キーの欄へキーを貼り付けます。「Notionの保存先を作る」を1回押し、完了を待ちます。ページURLを受け付けない場合は、エラーを確認し、ページIDの入力が使えるか確認してください。推測したIDは使いません。
  7. 操作画面に接続済みの表示が出た後、Notionの専用ページを開き直します。「QB問題マスター」と「QB解答ログ」が作られていることを確認します。表が空でも初回設定として正常です。

この操作では本人のNotionに保存先を作り、PCへ接続キーと保存先の設定を保存します。解答をしていない段階で、架空の解答記録を作ることはありません。途中で失敗した場合は、新しい接続や表を繰り返し作らず、止まったときの手順へ進んでください。

3．最初の記録を確認する

  1. Notionの設定後、ChromeでQBを新しいタブに開きます。本人がログインしてください。
  2. 普段の学習として1〜2問を解答します。Claudeに解答を代行させたり、試験用の解答をNotionに作らせたりしません。
  3. QB Study Friendの「記録を更新」を押し、問題番号、選択記号、正誤、解答日時を確認します。PC保存とNotion保存は別の状態です。「同期待ち」がある間は送信が終わっていません。
  4. 各記録の「保存済み・開く」からNotionを開き、同じ記録が1件ずつ保存されていることを確認します。問題の本文や解説を照合資料としてコピーする必要はありません。

「PCに保存」の件数は、このPCで取得した解答の件数です。iPhoneの解答はその数字に加算されなくても、同じNotionへ届いていれば次の復習計算の対象です。

毎日の学習と復習

学習する

start.cmd で記録サービスを起動し、ChromeでQBを使います。記録開始のボタンは不要です。学習後はPC側の同期待ちとNotion保存を確認してください。未送信の間に記録サービスを止めた場合は、次回起動後に再試行します。

復習候補を作る

操作画面で「今日の復習候補を作る」を押します。本人のNotionに届いているWindowsとiPhoneの解答履歴を読み、最大100問を選びます。基準は日本時間です。午前4時を1日の境界として、その対象日の翌朝4時より前に復習期限を迎える問題も候補に含めます。正誤と解答日時を使う既存の計算プログラムが選ぶため、Claudeが独自に候補を考える必要はありません。

通常学習・復習・未分類は別々に集計しますが、どの分類の正誤も復習時期の計算に使います。未判定の解答は履歴に残し、記憶状態の更新には使いません。既に保存した同日計画は固定され、その後の学習で当日のセットを自動的に入れ替えません。候補が少なくても100問まで埋めず、0問なら空のQBセットは作りません。

QBに同じセットを作る

本人が操作する場合は次の手順です。Claudeへ任せる場合は、Claude用の手順（任意のreview.cmd操作も掲載）と日常運用の指示文を使います。

  1. QBの問題セット一覧が操作できることを確認してから、操作画面の「QBセットの登録を始める」を押します。
  2. 表示されたセット名と完全に一致するセットをQBで探します。既にある場合はそのセットを使います。新規作成が許されている初回だけ、表示どおりの名前で1つ作ります。中断後に同じセットをもう一つ作らないでください。
  3. 候補の順に1問ずつ追加し、QBの保存を確定します。「追加日時の古い順」に並べ、最初の5問で番号と順序を確認します。
  4. 追加後にQBのセットを再読み込みし、全ページの全問題番号・件数・順序を確認します。連問が余分に入っていないか、重複や欠落がないかも確認します。
  5. QBで実際に読み取った番号を、操作画面の「QB上で確認した全問題番号」に入力します。候補一覧をそのまま貼るだけでは完成確認になりません。同じセットの検索画面URLを入力し、確認のチェックを入れて「内容を照合して復習セットを登録」を押します。
  6. 照合とNotionへのリンク保存の完了表示を確認します。Notionの候補ページも開き直して、同じセットへのリンクになっていることを確認します。

復習するときは、登録済みのセットのリンクから演習を開始してください。通常検索から同じ問題を解いた場合は通常学習となり、復習セットの実施数には含めません。入口が確認できない場合は未分類として保持します。

iPhoneと併用する場合

このWindows版は、iPhoneのSafari拡張が本人の同じNotionへ送った記録を読み込めます。ただし、iPhoneアプリはこのZIPに含まれません。別途提供されるiPhone版を導入してから接続してください。このWindows版を入れるだけでiPhone側の設定が済むわけではありません。

iPhone側には、本人の解答ログのデータソースID、問題マスターのデータソースID、復習計画の親ページIDと、本人の接続キーを設定します。配布者の設定を流用したり、IDを表の表示名から推測したりしません。IDの確認方法とiPhoneの導入手順は、その配布時の案内に従ってください。

Safariでは解答後に自動同期を試みますが、Safariを閉じた後も即時に送信される保証はありません。日次計画を作る前に、iPhoneの未送信がNotionへ届いていることを確認してください。Notion未到着の記録はWindows側の計算には入りません。

停止・自動起動・更新

したいこと操作と結果
記録サービスを止めるstop.cmd。学習中や復習セット作成中は避けます。停止要求を受け付けた表示だけで終了済みとはせず、記録用の黒いウィンドウが閉じ、操作画面が停止または未接続になることを確認します。既存の履歴は削除しません。
Windowsログイン時に起動するautostart-on.cmd を実行し、内容を確認して YES を入力します。これは記録サービスの起動で、毎朝のQBセット作成の予約ではありません。
ログイン時の自動起動を解除するautostart-off.cmd。起動中の記録サービスを止める場合は、別に stop.cmd を使います。
古い版から更新するこの版の導入は既存フォルダーを上書きしません。既に利用中なら、そのフォルダーと data を保持し、配布者から更新手順を受けてください。フォルダー削除による再インストールは行いません。

別の人へ渡すときは、受け取った元の配布ZIPを渡します。設定後の設置フォルダーや data は、接続キーと本人の学習履歴を含むため再配布しません。

止まったときに確認すること

状態まず行うこと
操作画面が開かない・未接続start.cmd から開き直します。同じプログラムを複数起動したり、別のプロセスを強制終了したりしません。
Notionの設定に失敗接続に専用ページへのアクセスがあるか確認します。作成結果が不明な場合は専用ページを開き直します。新しい表や接続を繰り返し作りません。
PCには保存されたが同期待ちネット接続と記録サービスの起動を確認し、しばらく待って「記録を更新」を押します。送信待ちや履歴ファイルは削除しません。
復習候補が0問初日や、まだ復習時期の問題がない場合は正常です。同期前の記録が残っていないかも確認します。候補を作るための架空の解答は追加しません。
QBセット作成が途中で停止同じ名前・同じURLのセットと保存済み候補から再開します。保存操作の応答が不明なときは再読み込みで確定するまで追加を繰り返しません。
番号・順序が一致しない、同名セットが複数ある完成扱いにせず停止します。既存問題を削除したり、別のセットを新しく作ったりせず、不一致を報告します。

相談するときは、実行した操作、画面の「確認用コード」、対象日、件数を伝えてください。接続キー、設定ファイル全文、セッション情報を含むURL、QBの問題文や解説は送らないでください。
