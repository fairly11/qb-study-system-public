今日の復習

同じNotionに届いたWindows・iPhoneの解答を使い、当日分の翌午前4時（日本時間）より前までに復習時期を迎える問題を選びます。初期上限は100問です。通常学習・復習・未分類の正誤を計算に使います。保存済みの同日計画は再計算せず、日本時間の午前4時に日付が切り替わります。初日は候補がない場合があります。

Notionの復習ページを開く

  1. QBで上記と同じセット名を検索します。既に存在する場合は、そのセットを開きます。
  2. 未作成の場合に限り、QBの画面でセットを作り、上記の順番どおりに問題を追加します。
  3. 完成したセットを「追加日時の古い順」に並べ、QB上の全問題番号を読み取り、下に入力します。
  4. セットを開いた検索画面のURLを貼り付けて照合します。

QBを開く

この画面はQBの中身を直接読みません。入力した番号と候補を照合します。問題文・選択肢の文章・解説は入力しないでください。

登録済みのQB復習セットを開く

通常学習は自動判定し、照合済みの登録セットから開始した演習を「復習」として記録します。開始元を確認できない場合は「未分類」になります。
