QB記録 Windows版

Windowsで解いた記録を、今までのNotionへ追加します。復習課題の計算は復習計算用Macで続けます。

1. Windowsに設置する

  1. ZIPをWindowsへ移して右クリックし、「すべて展開」を選びます。別添の connection-targets.json も移します。
  2. 展開先の install.cmd をダブルクリックします。管理者として実行しません。
  3. 公式Node.jsの実行環境を取得して検査します。CPUがARMかIntel/AMDかは自動判定します。インターネット接続が必要です。
  4. 完了後、start.cmd をダブルクリックします。記録サービスのウィンドウは開いたままにします。

設置先は %LOCALAPPDATA%\QBRecordWindows です。すでに存在する場合は上書きせず停止します。

2. 既存のNotionへ接続する

  1. Chromeの操作画面で、接続先ファイルを読み込みます。解答ログ、問題マスター、復習親ページの3項目が入ります。
  2. 既存の保存先にアクセスできるNotion接続キーを、秘密入力欄へ本人が貼り付けます。キーをチャットやメールへ貼り付けないでください。
  3. 接続操作を行います。保存先の形式と閲覧権限を確認します。新しいデータベースや試験用の解答は作成しません。
  4. 画面で接続済みと記録サービスの起動を確認します。

Notion接続を済ませてから記録を始めます。未接続中は記録サービスを起動しません。接続済みになった後の通信障害では、記録をPC内の送信待ちに保存します。

接続キーを手元で確認できない場合は、設定を止めたままにしてください。Macの設定ファイル全体には秘密や別端末のパスが含まれるため、コピーしません。

3. Chromeに記録拡張を読み込む

  1. Chromeのアドレス欄へ chrome://extensions を入力します。
  2. 右上の「デベロッパーモード」を有効にします。
  3. 「パッケージ化されていない拡張機能を読み込む」を選びます。
  4. %LOCALAPPDATA%\QBRecordWindows\browser-extension を指定します。フォルダ選択欄に入力できます。
  5. QBを開き直し、拡張の表示で記録状態を確認します。

確認済みの復習セットは「復習」、移動元の情報がない正当な演習は原則「通常学習」です。照合できない場合は未確認として残します。手動変更は、その演習のこれからの解答にだけ適用します。

4. 最初の記録を確認する

  1. 普段の学習で1〜2問解きます。確認のために架空の解答を作る必要はありません。
  2. 直近の記録で、問題番号、正誤、選択番号、日時、学習区分を確認します。
  3. 「Notion確認済み」になるまで待ち、Notionの同じ解答ログを開いて一致を確認します。

PCへの保存とNotionへの到達は別です。送信待ちは後で再試行します。保留が出た場合は画面のコードを確認し、履歴を削除してやり直さないでください。復習計算用MacはNotionへ届いた解答を、既存の計算ルールで取り込みます。

記録する情報

問題番号、選択番号、正誤、解答検出日時、学習区分を記録します。問題文、選択肢本文、解説、画像は取得・保存しません。第116回以前を含め、対応する問題番号の解答も記録します。

毎回の起動と停止

学習前に start.cmd、終了時は stop.cmd を使います。ログイン時にも起動したい場合だけ autostart-on.cmd でYESを入力します。解除は autostart-off.cmd です。復習課題を計算する予約は登録しません。

削除せず取り外す

記録サービスを停止し、自動起動を解除してからChromeの拡張を無効にします。Notionへの到達を確認するまで、設置先の data は保管してください。
