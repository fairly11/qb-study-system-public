QB Record for Windows

WindowsのChromeで解いたQBの記録を、MacやiPhoneと共通のNotionへ送るアプリです。復習候補の計算とセット作成はMacで行います。

用意するもの

  • Windows 11、Google Chrome、インターネット接続。
  • Notionの解答ログ、問題マスター、復習計画の親ページ。
  • 上記の保存先へアクセスできるNotion接続キー。
  • 保存先の3つのID。connection-targets.json があれば、画面から読み込めます。

1. Windowsに設置する

  1. ZIPを右クリックし、「すべて展開」を選びます。
  2. 展開先の install.cmd を通常ユーザーとしてダブルクリックします。管理者として実行しないでください。
  3. Node.jsの実行環境を公式サイトから取得し、ファイルの一致を検査します。ARM64とx64は自動判定します。
  4. 完了後、start.cmd をダブルクリックします。記録サービスのウィンドウは開いたままにします。

設置先は %LOCALAPPDATA%\QBRecordWindows です。すでに存在する場合は上書きせず停止します。保存済みの履歴がある場合は、フォルダーを削除して再インストールしないでください。

2. Notionへ接続する

  1. 操作画面で解答ログ、問題マスター、復習計画の親ページのIDを入力します。接続先ファイルがある場合は、読み込むと3項目が入力されます。
  2. Notion接続キーを秘密入力欄へ貼り付けます。キーはチャットやメールでは送らないでください。
  3. 「既存の保存先を確認して接続」を押します。プログラムが保存先の構造と読み取り権限を確認します。
  4. 接続済みと記録サービス起動中の表示を確認します。

初回のNotion接続が完了するまで、記録サービスは起動しません。接続後に通信が切れた場合は、解答をPC内に保存し、復旧後に送信します。

このアプリは既存のNotionを使用します。接続先の表を新しく作る機能はありません。接続キーやIDを確認できない場合は、先に利用中のNotionの接続設定を確認してください。

3. Chromeに記録拡張を読み込む

  1. Chromeのアドレス欄へ chrome://extensions を入力します。
  2. 右上の「デベロッパーモード」を有効にします。
  3. 「パッケージ化されていない拡張機能を読み込む」を選びます。
  4. %LOCALAPPDATA%\QBRecordWindows\browser-extension を指定します。フォルダー選択欄に入力できます。
  5. QBを開き直し、拡張の表示で記録状態を確認します。

解答は原則「通常学習」として記録し、確認済みの復習セットから始めた演習を「復習」とします。セットの照合に失敗した場合は「判定未確認」と表示します。拡張で学習区分を手動変更すると、その演習の以後の解答に適用されます。

4. 最初の記録を確認する

  1. 普段の学習で1〜2問解きます。
  2. 操作画面の直近の記録で、問題番号、正誤、選択記号、日時、学習区分を確認します。
  3. 「Notion確認済み」になったら、Notionの同じ解答ログを開いて内容が一致することを確認します。

PCへの保存とNotionへの同期は別の状態です。送信待ちは通信の復旧後に再試行します。「保留・要確認」が出た場合は表示されたコードを確認し、送信待ちや履歴を削除しないでください。Macの復習計算には、Notionへ届いた記録を使います。

記録する情報

問題番号、選択記号、正誤、解答検出日時、学習区分を記録します。問題文、選択肢本文、解説、画像は取得・保存しません。復習候補の選択範囲にかかわらず、対応する問題番号の解答を記録します。

起動と停止

学習前に start.cmd、終了時は stop.cmd を使います。停止後は、記録サービスのウィンドウが閉じたことを確認してください。

Windowsへのログイン時にも起動したい場合は autostart-on.cmd でYESを入力します。解除は autostart-off.cmd です。

利用をやめるとき

記録サービスを停止し、自動起動を解除してからChromeの拡張を無効にします。設置先の data には送信待ちと履歴が残るため、Notionへの同期を確認するまで保管してください。

検証の範囲

自動テストの結果は検証記録を参照してください。Windows実機での導入、アクセス権、実際のQB解答からNotionへの同期は未検証です。
