# QB記録 macOS版の導入

バージョン: `__VERSION__`

ソースのコミット: `__GIT_COMMIT__`

ChromeでQBを解くと、問題番号、選択した番号、正誤、時刻をMacに保存します。
この配布物にはChrome拡張と収集サービスが含まれます。

## 必要環境

- macOS
- Google Chrome 127以上
- Node.js 24.19.0以上、25未満
- QBの利用アカウント

Chrome Web Store経由の配布ではないため、自動更新はありません。
受け取ったZIPの送信元と、同時に配布されたチェックサムを確認してください。
チェックサムは、ファイルが配布時と同じ内容であることを調べる値です。

ZIPと同名の `.zip.sha256` を同じフォルダへ置き、そのフォルダで次を実行します。

```sh
shasum -a 256 -c qb-study-system-trusted-macos-v__VERSION__.zip.sha256
```

## 1. 展開場所

ZIPを展開し、今後も使い続ける場所へフォルダ全体を置きます。
特に `browser-extension` は、Chromeへ読み込ませた後に移動しないでください。
場所が変わると別の拡張として扱われ、既存の送信待ちへアクセスできなくなる場合があります。

ターミナルで展開先のフォルダを開き、内部ファイルも確認します。

```sh
shasum -a 256 -c CHECKSUMS.sha256
```

## 2. Chrome拡張の読み込み

1. Chromeで `chrome://extensions` を開きます。
2. 右上の「デベロッパー モード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」を押します。
4. 配布物内の `browser-extension` フォルダを選択します。
5. 拡張機能メニューから `QB capture status` をツールバーへ固定します。

## 3. 収集サービスの起動

Finderで `start-collector.command` をダブルクリックします。
ターミナルから起動する場合は、展開先のフォルダで次を実行します。

```sh
zsh ./start-collector.command
```

次の1行が表示されれば起動済みです。

```json
{"component":"history-collector","event_code":"COLLECTOR_LISTENING","port":8765}
```

使用中はターミナルを開いたままにします。
停止するときは `Control-C` を押します。
停止中の送信待ちはChrome内に残り、収集サービスの再起動後に再送します。

学習履歴は既定で次のSQLiteファイルに保存します。

```text
~/Library/Application Support/qb-study-system/qb-study.sqlite
```

## 4. 記録する

1. 収集サービスを起動します。
2. ChromeでQBの演習を始めると、問題画面で記録が自動開始します。
3. 確認済みの復習セットは「復習課題」、それ以外は原則「通常学習」です。照合に失敗した場合は「判定未確認」になります。
4. 区分を変える場合は拡張の「通常学習」「復習課題」を選びます。変更は以後の解答に適用します。
5. 一時停止と再開は、ツールバーから拡張の画面を開いて行います。

`Outbox` は送信待ち件数です。
0なら、受け付けた解答を同じMacへ保存済みです。
Notion同期を利用する場合、その完了は収集サービス側で確認します。

QBの画面構造に対応できない場合は `Capture: unsupported` を表示し、その画面の解答は記録しません。

## 更新する

1. 拡張の画面でOutboxが0であることを確認します。
2. 収集サービスを `Control-C` で停止します。
3. Chromeへ読み込ませている同じ `browser-extension` フォルダの中身を、新版の中身で置き換えます。
4. `chrome://extensions` の対象拡張で「再読み込み」を押します。
5. 新しい `start-collector.command` と `collector` フォルダで収集サービスを起動します。
6. 開いているQBタブを一度再読み込みします。

フォルダ自体を移動したり、別の場所から新しい拡張として読み込んだりしないでください。
Outboxが残っている場合は、更新前の収集サービスで送信を完了してから更新します。

## 削除する

1. Outboxが0であることを確認し、収集サービスを停止します。
2. `chrome://extensions` から拡張を削除します。
3. 配布フォルダを削除します。

拡張を削除すると、Chrome内のOutboxも失われます。
SQLiteの学習履歴は残ります。
履歴まで消す場合だけ、必要なバックアップを取ってから上記保存先のファイルを削除してください。

## 制限

- この配布物にはログイン時の自動起動設定はありません。
- 拡張は自動更新されません。
- QBの画面変更や未対応の問題形式では、取得を停止する場合があります。
- 収集サービスへの通信には認証がありません。同じMacで別のプログラムがポートを先に使った場合、誤送信や偽の保存応答を防げません。

[保存データとセキュリティ](SECURITY_AND_PRIVACY.ja.md) も参照してください。
