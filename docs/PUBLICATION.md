# 公開ソースの範囲と検証

この公開版は、Chrome、Macの収集と復習、iPhone / iPadのSafari、Windows記録専用版のソースをまとめたスナップショットです。
個人の環境設定を含む開発履歴を引き継がず、新しい履歴として公開しています。

## 公開対象から除外したもの

- 学習履歴の実データ、SQLiteファイル、実行ログ、バックアップ。
- 認証情報、個人のNotion接続先、署名用設定、証明書、プロファイル。
- 個人の端末名、ユーザー名入り保存先、会話の識別子、非公開ページへのリンク。
- 個人環境での解答件数、導入記録、署名期限などの運用記録。
- ビルド生成物、依存パッケージ本体、配布ZIP、過去のGit履歴。

設定例とテストには仮の値を使用しています。
第三者ライブラリの著作権表示は保持しています。
公開先アカウント名はGitHubのリポジトリ所有者として表示されます。

## 公開前に実行した検証

実行日: 2026-11-20。
使用環境: macOS、Node.js 24.19.0、pnpm 11.25.0。
`pnpm-lock.yaml` を変更せず、固定した依存関係で実行しました。

| 対象 | 結果 |
|---|---|
| `pnpm install --frozen-lockfile` | 成功 |
| `pnpm build` | 成功 |
| `pnpm verify` | lint、typecheck、test、buildすべて成功。49ファイル・764テスト成功 |
| `pnpm test:ios-native` | Swiftの54テスト成功 |
| `check-ios-build.sh` | 署名なしのiOS Simulator向けビルド成功 |
| `pnpm build:windows-recorder` | 成功 |
| `pnpm test:windows-recorder` | 18テスト成功 |
| 従来のWindows構成のbuild / test | ビルド成功、34テスト成功 |
| 公開ファイルの点検 | 個人の識別情報、実データ、秘密設定を除外。識別子とリンクの再点検を実施 |

自動テストは合成データ、一時保存先、模擬通信を使用しています。
この公開作業では、実際のQB操作、本番Notionへの同期、端末へのインストールは実行していません。
Windows実機のアクセス権、iPhone / iPad実機の署名とSafari権限、長時間のバックグラウンド動作は別途確認が必要です。
