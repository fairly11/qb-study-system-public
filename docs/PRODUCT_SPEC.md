# 記録と復習の仕様

## 対象と目的

医師国家試験QBを使う個人の学習を対象に、解答の自動記録と、履歴に基づく復習候補の選定を行います。
複数端末で解いた履歴をまとめ、端末を替えても同じ記録から復習を続けられる構成です。
標準タイムゾーンは `Asia/Tokyo` です。

## 解答の記録

Chrome拡張とSafari拡張は、QBの問題画面への移動に追従して記録を開始します。
問題番号、解答日時、正誤、選択した記号を取得し、解答ごとに識別子を付けます。
問題文、選択肢本文、解説、画像は収集しません。

結果画面を開き直しただけでは、新しい解答を作りません。
同じ問題を実際に解き直した場合は、別の解答として記録します。
画面構造や問題番号を確認できない場合は、その表示から解答を推測しません。

### 通常学習と復習

- 確認済みの復習セットから始めた演習は「復習」とします。
- 問題への直接移動など、復習セットの由来がない演習は原則「通常学習」とします。
- セットの照合に失敗した場合や識別子が不正な場合は、未分類または判定待ちとして扱います。
- 拡張の画面で学習種別を選ぶと、現在の演習の以後の解答に適用します。

手動選択で過去の記録は変更しません。
問題番号やセット名が似ていることだけでは復習と判定せず、手動で復習を選んだ場合も計画IDを推測しません。

## 保存と同期

PCでは、拡張の送信待ちから同じPCの収集サービスへ送り、SQLiteに保存します。
iPhone・iPadでは、Safari拡張内に保存してから、アプリと拡張が共有するSQLiteへ転送します。
受信側が保存を確認するまでは、送信側の記録を削除しません。

Notion同期を有効にすると、Notionを端末共通の履歴として使用します。
各端末のSQLiteは送信待ちと保存済み記録の控えを保持します。
Notionへの作成後は同じ記録を読み戻して一致を確認します。
通信の応答が失われた場合は、既存の記録を調べてから処理を再開します。

収集サービスを単独で使い、Notion同期を設定しない場合は、そのPCのSQLiteを原本とします。
Windows記録専用アプリは、Notion接続の設定が済むまで解答の受け付けを開始しません。
SQLiteファイル自体をクラウド同期で端末間共有する構成にはしません。

## 復習候補の選定

解答履歴を間隔反復モデルFSRS-6へ入力し、次の復習時期と想起率を推定します。
正解を `Good`、不正解を `Again` に対応させますが、この評価は計算用の値として元の正誤記録と分けて保持します。
日付しか分からない補完記録に、架空の解答時刻を付けてモデルへ入力することはありません。

新しい計画では、第116回〜第120回を対象に最大100問を選びます。
対象日の翌朝04:00（日本時間）より前に復習期限を迎える問題を候補に含めます。

選定は次の順で行います。

1. 停止中、当日正解済み、1問あたりの当日回数上限に達した問題、未来の手動復習日がある問題を除外します。
2. 手動の復習期日が来た問題、直近が不正解の問題、通常候補の順で優先します。当日解いた問題の再試行は後に回します。
3. 同じ優先分類の中で、知識タグや科目・分野の配分を考慮します。
4. 同じ配分条件では忘却リスクが高い順に選びます。第120回は比較用の忘却リスクを1.25倍にします。

第120回の補正は選定順だけに使い、モデルの予測値や復習期日を書き換えません。
候補が少なくても、対象外や期限前の問題で100問まで埋めません。
選定理由、除外理由、使用したモデルと選択器の版を計画に記録します。

## 問題セットと進捗

計画を一度保存した後は、同日中の再実行でも同じ候補と順序を使います。
問題セットの登録順序を一覧にし、ブラウザ上での登録後に問題番号、件数、重複、欠落、順序を照合します。
既存セットが予定した並びの先頭部分と一致する場合は、不足分から再開できます。

進捗はNotionへ届いた実解答から集計します。
問題の種類数と解答回数を区別し、不正解も実施数に含めますが、習得済みとは扱いません。
通常学習も記憶予測へ反映しますが、復習の進捗とは分けて数えます。

## 記録の精度

| 記録 | 表すもの |
|---|---|
| `AttemptEventV1` | 解答操作から取得した1回の解答 |
| `HistorySnapshotV1` | ある時点で確認した最終状態や集計回数 |
| `RecoveredAttemptV1` | 問題番号、日付、正誤を別の観測から確認した補完記録 |
| `StudyContextV1` | その解答が通常学習か復習かという分類 |

最終状態から、過去の解答回数、時刻、選択内容、正誤の並びを逆算しません。
元の解答は追記保存し、復習計算から書き換えません。

## 対応範囲

このシステムはQBの解答を代行せず、問題本文を外部へ取り込みません。
問題セットの登録には別途ブラウザ操作が必要です。
Google Sheets同期は未実装です。
画面変更への対応、端末の署名や権限、通信切断からの復帰は、[検証状況](VALIDATION.md)と各端末の導入手順を参照してください。
