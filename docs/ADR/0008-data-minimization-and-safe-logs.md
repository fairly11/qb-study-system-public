# ADR-0008: 保存項目とログを学習記録に必要な範囲へ限定する

- 状態: 採用
- 決定日: 2026-08-24

## 背景

復習計算に必要なのは解答の記録であり、問題本文や解説の複製ではない。
ログへ任意の文章を渡せる設計では、画面の本文や認証情報が混入する可能性がある。

## 決定

問題文、選択肢本文、解説、画像を取得・保存・ログ出力しない。
認証情報を解答データやログへ含めない。
システムログの項目は、重要度、コンポーネント名、イベントコード、時刻、許可した識別子、数値の件数に限定する。
自由形式のデータを格納する項目は設けない。

永続化する `producer`、`producer_version`、`source_system`、`source_record_id`、`question_group_id`、アルゴリズム名と版には、長さと文字種の制限を設ける。
文字種は `^[A-Za-z0-9][A-Za-z0-9@._:/+%#=~-]*$` に一致する値だけを許可する。
`set_name` は利用者が入力する名前として自由文を許すが、問題本文や認証情報の保存には使わない。

## 影響

障害調査にはエラーコードと関連する記録の識別子を使う。
ログ項目を増やす場合は、必要性と機密情報の混入を確認したうえでスキーマを変更する。
