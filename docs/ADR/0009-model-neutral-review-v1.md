# ADR-0009: V1の復習データを特定の記憶モデルに依存させない

- 状態: 採用。具体的な計算モデルは [ADR-0015](0015-daily-review-model-and-selector.md) を参照
- 決定日: 2026-08-24

## 背景

復習に使う記憶モデルや優先順位は、検証を通じて変更する可能性がある。
共通データ形式を特定のモデルに合わせると、モデルの交換時に保存処理や表示側も変更しなければならない。

## 決定

V1の問題状態と復習計画には、アルゴリズム名と版、計算の根拠、次回復習日、順位、選定理由を持たせる。
次回復習日が決まらない場合は `null` を許可する。
記憶強度の式や復習間隔の規則は、この共通契約の外で定義する。

## 影響

同じデータ形式で複数のアルゴリズムを比較できる。
モデルを追加・変更する場合は、その計算方法と検証条件を別のADRに記録する。
