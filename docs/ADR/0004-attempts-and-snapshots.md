# ADR-0004: 解答イベントと履歴スナップショットを分離する

- 状態: 採用
- 決定日: 2026-08-24

## 背景

一回の解答操作を観測した記録と、最終学習日や最新の正誤だけが分かる履歴表示では、確認できる情報が異なる。
両者を同じイベントとして扱うと、確認していない解答回数や時刻を作ることになる。

## 決定

個々の解答を表す `AttemptEventV1` と、履歴表示を表す `HistorySnapshotV1` を分離する。
スキーマ、レコード種別、保存テーブル、保存APIをそれぞれ別にし、スナップショットから解答イベントを作るAPIは設けない。
どちらのレコードにも、情報の取得元と日時・状態の精度を保持する。

## 影響

復習計算は、情報が不足している記録をそのまま扱う必要がある。
スナップショットにある回数や最終状態だけから、過去の正誤の並びを推定しない。
