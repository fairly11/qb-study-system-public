# ADR-0005: 解答の再送と解き直しを区別する

- 状態: 採用
- 決定日: 2026-08-24

## 背景

通信の再試行で同じ解答を二重保存してはいけない。
一方、同じ問題を同じ選択肢で解き直した記録は、内容が一致していても別の解答として残す必要がある。

## 決定

イベントIDを一意にする。
取得元のレコードIDがある場合は、取得元システムとの組にも一意制約を置く。
同じ識別子で保存対象の内容も同じなら `duplicate`、内容が異なれば `IDEMPOTENCY_CONFLICT` とする。
内容のハッシュだけには一意制約を置かない。
解答と選択番号のテーブルは、データベースのトリガーでも `UPDATE` と `DELETE` を拒否する。

## 影響

同じイベントを繰り返し送っても保存結果が変わらない冪等性を持たせつつ、実際の解き直しは保持できる。
記録元は再送時に同じイベントIDまたは取得元レコードIDを使う必要がある。
識別子の衝突は自動で上書きしない。
