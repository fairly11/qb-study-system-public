# ADR-0007: 問題識別子の正規化

- 状態: 採用
- 決定日: 2026-08-24

## 背景

同じ問題番号でも、半角・全角、空白、ハイフンの有無が異なることがある。
ただし、欠けた英字や連問関係を補うと別の問題へ対応付けるおそれがある。

## 決定

UnicodeのNFKC正規化、大文字化、許可された空白とハイフンの除去を行い、`119A12` 形式へ統一する。
`11565`、複数の英字、余分な記号は `invalid_format` として拒否する。
`question_group_id` は `question_key` とは独立した識別子とし、問題番号の連続性から連問関係を推定しない。

## 影響

意味が変わらない表記の違いを統合できる。
問題を一意に特定できない入力は未解決のまま残し、確認できる情報が得られてから対応付ける。
