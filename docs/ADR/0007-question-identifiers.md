# ADR-0007: 問題識別子の正規化

- Status: Accepted
- Date: 2026-08-24

## Context

同一問題番号に半角・全角、空白、ハイフンの表記差があります。一方、欠けた英字や連問関係を推測すると誤対応が起きます。

## Decision

NFKC、大文字化、許可された空白・ハイフン除去を行い、`119A12` 形式を正規形とします。`11565`、複数英字、余分な記号は `invalid_format` とします。`question_group_id` は不透明な任意IDとして `question_key` と分離し、連番などから推定しません。

## Consequences

安全な表記揺れは統合できます。情報不足のidentifierは未解決のまま残り、手動または直接証拠による解決が必要です。
